# Description

Contractor's Stambha is an offline desktop app for construction businesses: BOQ, daily site reports, worker attendance, payroll, billing, job costing, WIP and a double-entry ledger. Runs natively on macOS, Windows and Linux with Bikram Sambat dates, Excel/PDF exports, automatic backups and fully local data — no cloud, no accounts, and no telemetry.
